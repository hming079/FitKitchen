# FitKitchen agent guidance

- For frontend work, read [frontend/AGENTS.md](frontend/AGENTS.md), including its Lovable boundaries.
- Before building or changing UI, read [the design system](docs/design/DESIGN_SYSTEM.md) and use [fitkitchen-ui](.agents/skills/fitkitchen-ui/SKILL.md). Search existing domain/shared components and `frontend/src/components/ui` first; reuse semantic tokens and primitives.
- Before finishing UI work, apply [fitkitchen-ui-review](.agents/skills/fitkitchen-ui-review/SKILL.md). Report actual desktop/mobile observations, states checked, and anything not visually verified.
- These skills live in the repository. If your environment does not discover them, read the linked files explicitly; do not assume automatic discovery or install personal copies.
